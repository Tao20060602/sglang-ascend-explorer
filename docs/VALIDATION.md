# 初版发布的工程验证

## 连线缺陷与修复范围

旧版把关系和手工布局混在同一个渲染函数中，并复用固定折线通道。一般规则应当是：不同逻辑连接有明确的端点与独立路径；只有显式建模的总线才允许共享线段。

通过原始页面的实际 SVG 路径，检测到全景图中 3 对不同连接存在正长度的共线区间。新版保留模块内容，把关系数据从坐标计算中分离，并在所有层级统一使用 ELK 的正交布局和独立端口。

旧版排查命令：

```bash
rg -n 'rootRows|pagedRows|route===|route ===' <原始可视化文件>
```

命中的是全景位置表、分页内核位置表、共享通道及横向分支。新版项目不再使用这些手工坐标分支：所有层级统一进入同一个 ELK 布局入口。

## 真实页面验证

```bash
npx playwright install chromium
npm test
```

四个端到端场景通过：

1. 从全景展开到 Attention → Decode → Paged Attention，查看输出契约、选择关系并检查固定版本源码入口。
2. 对比 Attention 契约相同、KV 布局改变以及启用图执行三种条件，核对 A/C/S 范围和步骤操作；再走完其他三个案例。
3. 检查全部 15 个非叶层级的实际渲染几何：节点内无穿线、不同连接无共享线段、箭头落在目标节点端口区域、标签不遮挡节点。
4. 检查键盘进入模块、缩放、窄屏布局和深色模式。

每次运行产生 `test-results/layout-manifest.json` 与截图。清单包含各层的节点数、连接数及检测结果，便于后续内容更新后重新复核。它检查的是已渲染图形，不是对 ELK 算法做同构实现。

## 维护复杂度

- 运行时只增加一个布局依赖 ELK；没有应用框架、后端服务、登录系统或远程内容 API。
- Playwright 只用于开发验证，不随页面运行。
- 模块描述、交互关系、工程说明、渲染与样式分开维护。新增内容无需编辑坐标。
- 边的端口和路径由布局器确定；方向、载荷和影响由维护者明确填写。
- 新增独立项目的代码增长用于可维护页面、明确的关系契约、详细说明与端到端验证；第三方布局实现未经修改，不纳入自有代码审阅结论。

新增自有内容按区域统计（不含第三方分发与图片）：模块/关系/渲染源码 2,471 行；页面与样式 859 行；构建与预览脚本 52 行；端到端测试 311 行；说明与学习文档另列。这个版本是新增独立项目，净增长用于可编辑的内容、交互说明和验证，未增加第二套布局实现。

审阅范围包括本项目的自有页面、样式、模块与案例数据、关系数据、解释、应用代码、构建/预览脚本、测试和文档；第三方 ELK 分发只核对来源、版本和许可证，不宣称逐行审阅。

## 限制

几何检查针对单个层级的逻辑图；允许互不连接的线在不同层次交叉，并用背景间隔区分。它不证明所有人工工程解释都完整覆盖上游，也不替代 NPU 正确性、容量或性能验证。

## 模型因素扩展验证（2026-10-27）

增加真实页面测试覆盖：

- 模型切换改变真实状态节点、Attention 关系与源码链接；从 DeepSeek 共享 KV 切换到 Kimi 双状态，再切换到 GLM MLA / Index-K。
- Kimi 的主 KV 精度场景保持 KDA 递推精度；前缀恢复场景涉及 KDA 状态。容量场景不把 Attention 内核标成需要重写。
- 模型与 KV 意图的分享链接可重载；无效模型、意图和不属于当前模型的图层有确定的落点。
- 点击影响路径能进入实际模块；桌面、深色和 360px 窄屏检查新控件和状态图。
- 几何检查扩展为通用接口 15 层 + 三个模型各 6 层，共 33 个视图，检查独立线段、箭头目标、穿线和标签遮挡。

测试验证页面的分析与交互契约，不证明 NPU 内核正确性或性能。没有 NPU 设备实测。模型 checkpoint 来源与源码覆盖边界见 [SOURCES.md](SOURCES.md)。

新增数据和规则集中在 `src/models.js`，复用现有 ELK、关系表、目录、说明面板与案例步骤；没有新增运行时依赖、后端或第二套布局。审阅范围为本次修改的自有源码、页面、样式、端到端测试和文档；未修改第三方分发。

最终 `npm test` 的 7 个端到端场景全部通过；33 个图层的几何检查没有穿线、重合线段、错误目标或标签遮挡。另对照本地固定上游提交核对所有活跃节点的源码路径与行号范围，无缺失路径或重复父归属。

本次自有源码净增 997 行，其中模型画像与场景规则 919 行；页面与样式净增 94 行，测试净增 164 行。增长用于三种真实状态拓扑、四类不同改动契约、来源与覆盖说明，以及相应交互验证。仍只有一个渲染器和一套端口布局规则。

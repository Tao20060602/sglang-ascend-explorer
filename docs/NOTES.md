## 已确认的理解

- 模型结构、公共接口和设备实现处于不同层次；适配首先要明确发生变化的契约。
- 输出 shape 相同仍可能有 head 或 token 排列差异，需要检查语义和数值。
- 切换 Attention 后端不一定改变 KV 或调度；变化范围取决于实际接口差异。
